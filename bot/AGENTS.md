# Бот заявок «Ранг Авто» — правила для ИИ-агента

Отдельный проект внутри репозитория сайта: TypeScript + grammY, Node 22, запуск через tsx (сборки нет).
Сайт (Next.js в корне) этот код не импортирует, и наоборот.

## Команды
- `npm run dev` — бот с автоперезапуском (long polling, нужен `.env`, см. `.env.example`)
- `npm run typecheck` — проверка типов; запускать после каждого изменения
- `npm run widget:check` — размер виджетов против лимитов Telegram

## Где что лежит
- `src/quiz.ts` — вопросы подбора (бюджет, руль, срок). Новый вопрос = новый элемент массива, остальное подхватится само.
- `src/texts.ts` — все тексты для пользователя. `src/brand.ts` — цвета айдентики (как на сайте).
- `src/bot.ts` — сценарий: /start → подбор (виджет или кнопки) → машины из таблицы → «Хочу эту» → контакт → заявка.
- `src/catalog.ts` — машины из `data/cars.json` (фильтр по рулю и цене), фото `data/photos/<id>.jpg`; ссылка «Похожие» —
  страница марки в catalog.rangauto.ru (список марок грузится в фоне, пока нет — каталог страны).
- `data/` — каталог бота: `cars.json` и фото. Не править руками — генерируется из Google-таблицы (см. ниже).
- `src/lead.ts` — доставка заявки: чаты `LEAD_CHAT_IDS` (с кнопками статуса) и/или сайт `LEAD_API_URL`.
- `src/server.ts` — HTTP: `/` Mini App, `/api/cars`, `/api/lead` (подпись initData проверяет `src/miniapp/auth.ts`), `/health`.
- `src/miniapp/index.html` — Mini App (одна страница без сборки, цвета и вопросы подставляются из brand.ts/quiz.ts).
- `src/session.ts` — состояние пользователя в памяти (сбрасывается при перезапуске).
- `src/widgets/*.html` — виджеты Bot API 10.4; `render.ts` подставляет `{{переменные}}` и проверяет лимиты.

## Каталог из таблицы
Источник: Google-таблица (id в `scripts/import-sheet.py`), 6 вкладок: левый руль до 2 / 2–3 / 3–4 / 4+ млн, правый руль до 2 / 2+ млн.
Колонки: Марка, Модель, Цена, Год, Характеристики, Фото. Ссылка на фото стоит один раз на вкладку (папка Яндекс.Диска,
файлы «Марка Модель.jpg»); фото к машинам подбираются по названию автоматически. Если ссылка стоит у самой машины
(не в первой строке вкладки) — берётся первое фото из её папки.
- Обновить каталог: `python3 bot/scripts/import-sheet.py` из корня репозитория (нужен `pip install pillow`), закоммитить `bot/data/`.
  Фото уже скачанных машин не перекачиваются; `--photos` — перекачать все.
- Машины без фото в списке, который печатает скрипт, показываются текстом. Чтобы появилось фото — назвать файл в папке
  как «Марка Модель» или положить его в нужную вкладку.
- Бюджет фильтруется по цене машины, а не по вкладке: границы в `quiz.ts` совпадают с вкладками (до 2 / 2–3 / 3–4 / от 4 млн).

## Деплой
- Mini App открывается по `PUBLIC_URL` (технический домен App Platform): кнопка меню и кнопка после /start.
- Локально Mini App: `MINIAPP_DEV=1 npm run dev` → http://localhost:8080/ (заявки без подписи Telegram — только для проверки).
- Timeweb App Platform (Амстердам), `bot/Dockerfile`, порт 8080, `/health`. Пуш в `main` → автодеплой.
- Mini App живёт на https://tg.rangauto.ru (на техническом домене twc1.net сертификат не выпустился).
- Переменные окружения задаёт `Ad-Reach/infra` (`terraform/bot.tf`); руками в панели не менять.
- Новая переменная окружения → добавить в `src/config.ts`, `.env.example` и `bot.tf` в infra.

## Виджеты (Bot API 10.4) — важное
- Выключены по умолчанию (`WIDGETS=on` — включить).
- grammY их ещё не знает: вызовы только через `src/widgets/api.ts` (`api.raw`).
- Работают только в личке с ботом. Нет полей ввода, нет сети, нет внешних картинок/шрифтов.
- html ≤ 32 КБ и ≤ 4 КБ после zlib; запрос виджета ≤ 64 байт, ответ ≤ 1024 байт за 15 с; chat_data ≤ 1024 байт.
- Состояние виджета — только `chatData`/localStorage: виджет может быть пересоздан в любой момент.
- `TelegramWidget.request()` вызывать синхронно в обработчике тапа.
- Если `sendWidget` падает, всегда должен быть запасной вариант обычными кнопками.
- С 13.11.2026 в проде обычным ботам sendWidget отвечает `INPUT_MEDIA_WIDGET_NOT_ALLOWED` — это политика Telegram,
  не баг. Бот сам переключается на кнопки. Проверять виджеты — на тестовом сервере (`TELEGRAM_TEST_ENV=1`).
- В разметке виджета нельзя `on*`-атрибуты (вырезаются) — обработчики вешать из JS (`el.onclick = ...`).
- Документация: https://core.telegram.org/bots/widgets

## Правила
- Не коммитить `.env` и токены.
- catalog.rangauto.ru блокирует User-Agent со словом «Bot» — не менять `CATALOG_USER_AGENT` на такой.
- Тексты — по-русски, коротко, для человека, который ничего не знает про импорт авто.
